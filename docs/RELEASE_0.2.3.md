# 0.2.3：受控工作能力 / Controlled Work Capabilities

0.2.3 让 LivingAgent 从“只能聊天”扩展为可以完成一组宿主声明、可审计且有明确权限边界的真实工作。版本保留 0.2.2 的自动记忆闭环，并且不开放任意 Shell 或模型自由工具调用。

## 工作区文件

- 所有者可在聊天中列出目录、读取 UTF-8 文本、搜索文本和写入明确提供的内容。
- 多个用分号或换行分隔的明确动作形成有依赖关系的持久化步骤；前一步失败会停止后续步骤。
- 写入采用同目录原子替换，进入 `waiting_confirmation` 后才允许所有者确认落盘。
- 重启不会自动重放中断的写入，绝对路径、目录逃逸、工作区外符号链接和敏感凭据路径会被拒绝。

## 网页与搜索

- 支持读取公网 HTTP(S) 文本页面，以及通过可配置 HTML 搜索端点返回有来源的搜索结果。
- 默认要求 HTTPS，并限制重定向次数、响应类型、响应大小和超时。
- 每次请求及重定向都会检查精确主机白名单（如配置）和 DNS 解析结果，拒绝回环、私网、链路本地和保留地址。
- 文件、网页和搜索结果以 `UNTRUSTED_TOOL_RESULT` 进入回复模型，不能追加任务、授予权限或触发写入。

## 每日计划

- 所有者可在聊天中查看、创建或替换每日计划。
- 支持追加项目而不覆盖现有项目，并可按标题把计划项更新为进行中、完成或跳过。
- 创建、追加和状态更新都必须逐次确认，并保留数据库提交证据。

## 权限与限制

- 工作区和私人每日计划能力仅允许配置的所有者使用，即使普通成员取得临时授权也会被能力代理拒绝。
- 网页只读能力仍可供经过认证的成员使用，但不能访问私网或读取宿主秘密。
- 版本不支持 Shell、进程启动、文件删除、环境秘密、任意补丁、第三方发送或开放式模型动作规划。

## 配置变化

```yaml
work_workspace_root: .
work_max_file_bytes: 1048576
work_web_search_endpoint: https://html.duckduckgo.com/html/
work_web_allowed_hosts: []
work_web_allow_insecure_http: false
work_web_timeout_seconds: 15.0
work_web_max_response_bytes: 1048576
```

生产环境应把 `work_workspace_root` 指向专用目录，并按部署需要配置精确网页主机白名单。网页搜索依赖外部提供方可用性，可替换为兼容的 HTML 搜索端点。
